# M7 — First complete solo extraction loop

Approved after M6 acceptance (“go next”, 2026-11-11). This is the plan's first design gate: stop for the developer's fun verdict before M7b.

## Result and boundaries

The default page is a complete solo expedition: leave Sanctuary, find one relic in the outer ring, take it with **E**, and carry it back into Sanctuary while the maze shifts on its own every 45 seconds. The run ends exactly once: **extracted**, **failed** (crushed) or **abandoned**. The result screen shows time and shifts survived and offers **New run** (fresh seed) or **Retry this seed**.

No inventory, rewards, persistence, deadline, creatures, sound or art. Reference scenes are unchanged.

## Rules (`game/generatedRun.ts`)

- **Relic placement** (`placeRelic`): an outer-ring room centre, never a landmark room, among the farther half of outer rooms by static route length (gates closed), chosen with a seeded RNG stream. Deterministic per seed; no generator version change.
- **Run status**: `ready` → `out` (on first leaving the plaza) → exactly one of `extracted`, `failed`, `abandoned`. Terminal runs are fixed records: further steps, shifts, pickups and abandon calls change nothing.
- **Run clock** (`runTicks`): counts fixed 1/60 s steps while `out` and alive, from the step after leaving.
- **Automatic shifts**: while `out`, alive, unfrozen and the maze is idle, `autoTicks` counts up; at 45 s (`AUTO_SHIFT_SECONDS`, 2700 steps) a normal validated shift is requested (2 s warning, opening, closing, cooldown). The countdown restarts after each request from idle. Freeze (debug) pauses it. **G** remains as a debug force and also restarts the countdown. No automatic shifts before the run starts.
- **Pickup** (`interactGeneratedRun`): E takes the relic when the body centre is within 1.6 m (`RELIC_REACH`) of it, the player is alive and the run is not over. Ownership is unique: once carried it cannot be taken again.
- **Extraction**: entering the Sanctuary plaza while `out` and carrying the relic ends the run as `extracted`. Entering without it does nothing.
- **Failure**: being crushed ends the run as `failed`; a carried relic is lost. Gates still finish moving after death (accepted M1 rule).
- **Abandon** (`abandonGeneratedRun`): from the pause menu once a run has started; ends it as `abandoned` with nothing secured.
- Debug teleports work during a run and are counted on the result screen; they are refused once the run is over.

## Interface

- 3D: a floating pale-blue crystal at the relic room centre with a tall **blue beam** visible above the walls from anywhere; a **gold beam** over Sanctuary. The crystal and blue beam disappear when taken. Neither has collision.
- HUD panel: objective (leave → find the relic under the blue beam → carry it back under the gold beam), run time, shifts, ring, shift phase and notice. An **E · Take the relic** prompt appears in reach.
- Pause panel: **Abandon run** while a run is underway. Result panel: *Relic secured* / *Crushed* / *Run abandoned*, time and shifts, relic lost/left notes, debug-teleport count; **New run** and **Retry this seed**.
- Debug panel: run status, relic room and seconds to the next automatic shift. Events include run start/end and relic taken. Bug reports are now format 2 and carry status, relic, run clock and countdown; format 1 reports are refused.

## Human acceptance checklist (the fun test)

1. Play **five complete runs on three seeds** without the debug map or teleports. At least one should end in extraction; note your times and shifts.
2. In at least one run, notice a shift change your way home and find another route.
3. **Abandon** one run from the pause menu: the result says nothing was secured.
4. Get crushed once on purpose: the run fails, the relic is lost, Retry works.
5. Check the E prompt appears only next to the relic, and the beams help without solving the maze.
6. **Verdict**: Is planning and re-planning the return fun? Which moment was the best decision you made? What felt dull or unfair: walking time, beam visibility, shift frequency, crush danger? The plan says to fix navigation and pacing here before adding anything else.

## Automated checks

- 200 seeds: relic in the outer ring, in the farther half by route length (±1), not a landmark room, deterministic, clear for standing.
- Pickup range on both sides of 1.6 m; unique ownership; no pickup when dead or after the run.
- Status: ready until leaving; clock starts the step after; no extraction without the relic; extraction exactly once with it; terminal runs immutable (steps, abandon, shifts).
- Abandon from ready and from out, with relic-lost note; once only.
- Automatic shifts: none while ready; first request at exactly 2700 idle steps; the next 2700 idle steps after the maze settles; freeze holds the countdown; G resets it.
- Crushed while carrying: fails once with relic lost.
- Three seeds end to end: walk to the relic, take it, let a real automatic shift complete, walk the new route home, extract with time and shifts in the event.
- Reports round-trip carrying, status, clock and countdown and continue identically for 3000 steps; format 1 refused.
- Production browser: run starts on leaving the plaza and the debug countdown runs; E prompt, pickup, objective change; extraction result with shifts and debug teleports; Retry this seed resets the run on the same seed; Abandon (hidden before first start) gives the abandoned result; New run loads a different seed. M0–M6 checks updated for the new HUD (landmark checklist removed; landmarks remain in the world).
